#### Reflection :



## What challenges did you face when refactoring your code to use Bootstrap?

Overriding Default Styles: Tailoring default colors, spacing, and component designs forces you to either load secondary stylesheets after Bootstrap or reconfigure Sass variables, creating long-term maintenance challenges.
## How did using Bootstrap utility classes and components simplify your styling process?

Using Bootstrap simplified my styling process by making the layout and functionality much easier to configure. Once I understood the core concept of rows and columns, structuring the webpage became far more intuitive and efficient.
## In what scenarios might you choose not to use Bootstrap and write custom CSS instead?

I would choose custom CSS over Bootstrap when a project requires deep customization that relies on Sass. If I don't yet have a strong grasp of Sass, trying to configure Bootstrap's variables and build tools adds unnecessary complexity, making plain CSS much faster and easier to manage.
